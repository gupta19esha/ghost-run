How it plays

Four minutes a day.

Each day you play one month. A few decisions, then the month runs and you see what it did to your money and your life. Then the game waits for tomorrow, the way a real month does.

How the numbers work

Every figure comes from a simulator, not a language model.

Salary, rent, EMIs, tax, inflation and market returns run through a simulation written in plain code. The same choices give the same life, every time.

The only words a model may write are a few sentences about the ghost's life. Every figure in them is checked against the simulation before you see it, a draft with one wrong number is thrown away, and the page shows you each check.
